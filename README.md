# DDialer - 100% White-Label Android Softphone App
Target SDK 36 (Android 16 / versionCode 2, Version 2.0.0) / Min SDK 24.

## 🚀 Build APK with GitHub Actions:
1. Push this folder to your GitHub repository.
2. Go to Actions -> 'Build DDialer Android APK & AAB' -> Click 'Run workflow'.
3. In 3 minutes, download 'ddialer-release-universal-apk' under Artifacts and install on your phone!

## Local CLI Build:
flutter pub get
bash build_apk.sh
